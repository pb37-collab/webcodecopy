## Final instructions for the site (owner-confirmed 2026-10-07; this overrides any ambiguity in the chart)

| Step | What to use | Dose | How |
|---|---|---|---|
| 1. Mix | Non-chlorinated water, mixed fresh each time | **2 mL per 1 L** of each product used | See below for which product goes where |
| 2. Prep soil (~9 and ~5 days before planting) | **GroMax + RootMax together** | 2 mL + 2 mL per 1 L | Soil drench |
| 3. First spray (a few true leaves) | **GroMax only** | 2 mL per 1 L | Light leaf mist, morning or evening; don't soak |
| 4. Routine (veg) | **GroMax** spray → wait 5–7 days → **RootMax** drench → wait 5–7 days → repeat | 2 mL per 1 L each | Alternate |
| 5. How much | Drench ~8 oz (237 mL) per plant; 5 plants ≈ 40 oz per feeding | — | Around the roots |
| 6. Flowering | **RootMax drench only**, no leaf spraying | 2 mL per 1 L | Continue root drenches |
| 7. Finish | Stop all use ~2 weeks before harvest | — | — |

Short version: **GroMax = leaf spray. RootMax = soil drench. Both together = soil prep before planting.**

## Verbatim steps

### Step 1: Mix your solution
- Graphic: GroMax dropper **2 mL** + RootMax dropper **2 mL** into a **1 liter** jug.
- "Use 2 mL per 1 liter of water (both products)"
- "Always use non-chlorinated water"
- "Mix fresh each time"
- Callout: "USE ONLY NON-CHLORINATED WATER"

### Step 2: Prep soil (before planting)
- "~9 days before planting: Drench soil with Root Max solution"
- "~5 days before planting: Drench again with Root Max"

### Step 3: First spray (early growth)
- "Once the plant has a few leaves: Spray Grow Max on leaves"
- "Lightly coat leaves (don't soak)"
- "Spray in morning or evening"

### Step 4: Ongoing routine (vegetative stage)
"REPEAT THIS CYCLE:"
1. Spray Grow Max (foliar)
2. Wait 5–7 days
3. Drench soil with Root Max
4. Wait 5–7 days
5. Repeat

"KEEP ALTERNATING EVERY 5–7 DAYS"

### Step 5: How much to use
- Soil drench: "~8 oz (237 mL) per plant around roots"
- "For 5 plants: ~40 oz total per feeding"

### Step 6: Flowering stage
- "Stop spraying leaves (avoid damaging buds)"
- "Only use Root Max in soil"
- "Continue root drenches"

### Step 7: Finish
- "Stop all use ~2 weeks before harvest"

### Quick rules to remember (footer strip)
- Grow Max = spray leaves
- Root Max = feed roots
- Alternate every 5–7 days
- Spray only when it's cool (morning/evening)
